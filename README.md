# 📘 Student Attendance Management System

## 📌 Overview
The **Student Attendance Management System** is a database-driven web application designed to automate and streamline attendance tracking in educational institutions. Traditional manual methods are often time-consuming, error-prone, and lack real-time accessibility. This system leverages **MySQL** and a **Flask-based web interface** to ensure accuracy, reliability, and ease of use.

Teachers can record daily attendance, generate reports, and monitor class trends, while students can view their own attendance records and percentages. The system supports subject-wise tracking, date filtering, and role-based access control for secure and personalized experiences.

---

## 🚀 Features
- **Teacher View**
  - Digital attendance recording
  - Class schedule management
  - Attendance summaries and detailed reports
  - Pattern identification and student communication

- **Student View**
  - Personal attendance dashboard
  - Subject-wise percentage tracking
  - Transparency in records and discrepancy alerts

- **General Features**
  - Role-based access control (teachers vs. students)
  - Real-time data access from anywhere
  - Automatic calculation of attendance percentages
  - Secure, centralized database storage

## ⚙️ Proposed Solution
The system provides a **web-based platform** with distinct views for teachers and students:
- Teachers: Manage attendance digitally, generate reports, and reduce manual effort.
- Students: Track attendance percentages, stay informed, and take responsibility for their progress.

By combining **Flask’s lightweight web framework** with **MySQL’s secure data handling**, the application ensures scalability, transparency, and efficiency for modern institutions.
